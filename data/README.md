# Data: the short-pay checklist

The checklist is the asset that compounds. It starts generic and goes local.

## Contents (planned)

- `data/checklist.md` — the living checklist of short-pay patterns, keyed by state statute (TX Ch. 1813, WAC 284-30-390, IL appraisal path).
- `data/outcomes.json` — every file's outcome: carrier, procedure, ZIP, photo-set density, whether the flag produced a higher settlement or appraisal award.

## The map

Volume turns the checker into a labeled corpus: which carriers short-pay which procedures in which ZIPs, which photo sets correlate with successful appraisal outcomes, which missing lines reappear after the human gate. Do not sell the map before real files have closed through it.
